## Project Overview

Multi-crop demand forecasting system for Peru's agro-industrial sector (primary target: lime/limón). Integrates four heterogeneous data sources — MIDAGRI (crop statistics), NASA POWER (climate), INDECI (disasters), Agraria.pe (news) — through a 10-activity ETL pipeline into a Star Schema DWH, then applies NLP (BETO transformer) and LSTM-Attention for demand/price prediction with SHAP explainability.

**Python version: strictly 3.11** (TensorFlow is incompatible with 3.13+).

## Running the Project

```powershell
# Activate virtualenv (Windows)
.\venv\Scripts\Activate.ps1

# Quick demo (Agro + Weather + Features + News scraping)
python main.py

# Full Phase 1 pipeline (all 10 ETL activities)
python main_fase1.py

# Run a specific activity (1–10)
python main_fase1.py --actividad 3

# NASA-specific pipeline
python main_nasa_pipeline.py
```

Notebooks in `pipeline/` are the primary execution environment. Run them sequentially: `actividad_01_*.ipynb` → `actividad_10_*.ipynb`.

## Architecture

### Two-Phase Design

**Phase 1 — Data Engineering** (`pipeline/`, `src/data_processing/`):
10 sequential activities: environment setup → data loading (4 sources) → EDA → quality audit → cleaning → DWH integration → Star Schema design → PostgreSQL creation → ETL → re-exploration.

**Phase 2 — Feature Engineering + NLP** (`notebooks/fase2/`, `src/`):
Sentiment analysis via BETO → cyclic temporal encoding (sin/cos) → lag features (t-1, t-2, t-3) → normalization. Output: 88-column master dataset in `data/processed/`.

### Core Classes (`src/`)

| Module | Class | Responsibility |
|---|---|---|
| `src/agro/processor.py` | `AgroProcessor` | Load MIDAGRI CSV, filter by crop, IQR outlier removal, validate ≥24 months |
| `src/weather/processor.py` | `WeatherProcessor` | Load NASA/SENAMHI CSV, standardize district names, impute missing values |
| `src/features/builder.py` | `FeatureBuilder` | Merge datasets by ANHO+MES+UBIGEO, generate lag features, add cyclic seasonality |
| `src/models/lstm_attention.py` | `LSTMDemandForecaster` | Build/train/predict LSTM+Attention Keras model |
| `src/scraping/news_scraper.py` | `NewsScraper` | Ethical scraping of Agraria.pe with robots.txt compliance and random delays |

### Code Organization Rule

All new core logic must be **class-based and placed in the appropriate `src/` subdirectory**. Notebooks (`pipeline/`, `notebooks/`) are sandboxes only. The `dashboard/` directory is reserved for Streamlit/Dash frontend (not yet implemented).

### Data Flow

```
sources/ (raw CSVs)
  → pipeline/actividad_*.ipynb  (ETL, cleaning, DWH)
  → data/processed/             (master dataset, 88 cols)
  → notebooks/fase2/            (NLP, lags, scaling)
  → models/                     (trained LSTM + scalers)
  → dashboard/                  (Streamlit frontend, pending)
```

### Pipeline Configuration

`pipeline/config/pipeline_config.json` is generated by Activity 1 and controls directory mappings, time range (`ANHO_INICIO`/`ANHO_FIN`), and `CULTIVO_TARGET`.

### Database

`database/` contains PostgreSQL DDL for the Star Schema DWH:
- `dwh_star_schema_v2.sql` — current version; fact table `hechos_produccion` + dimension tables
- `dwh_nasa_clima_schema.sql` — climate-specific schema

## Model Performance Metrics (2026-06-01)

### Test Set Results (12 meses: ene 2024 – ene 2025)

| Model | MAE | Notes |
|---|---|---|
| **GM_v2** | **0.0646** | NLP mejorado con módulos M1+M2+M3+M4 |
| XGBoost | 0.0471 | Nuevo competidor — mejor MAE absoluto |
| TCN | 0.1860 | Nuevo competidor |
| Naive (baseline) | 0.0161 | Baseline de referencia |

### Observaciones clave

- **8 de 12 meses** del test presentaron shocks de precio >20%
- **Shock máximo:** enero 2025 con 1021% de variación
- **Attention Bahdanau (Canal B):** gradiente de atención t-5=0.128 → t=0.210 en agosto 2025 (captura de rezago climático)

> XGBoost lidera en MAE pero no captura dependencias temporales ni shocks; GM_v2 es el modelo principal del sistema. El Naive baseline bajo (0.0161) refleja la alta autocorrelación de la serie en periodos no-shock.
