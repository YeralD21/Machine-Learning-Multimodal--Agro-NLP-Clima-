¿Por qué el despliegue es más difícil que el entrenamiento?

En investigación académica, el modelo se evalúa una vez con datos históricos. En producción, el modelo debe predecir cada mes con datos nuevos, manejar valores faltantes, detectar cuando los datos de entrada son atípicos y alertar al gerente antes de hacer una predicción incorrecta. El 80% del tiempo de un proyecto ML real se gasta aquí — no en el modelo.

  • ✗ Los datos de NASA POWER llegan con 2–3 días de retraso
  • ✗ INDECI no siempre reporta a tiempo
  • ✗ El StandardScaler del train puede desincronizarse
  • ✗ El Niño de 2026 puede ser diferente al de 2023
  • ✓ Pipeline de validación + alertas de drift + re-entrenamiento semestral
